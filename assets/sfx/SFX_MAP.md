# SFX map

One row per sound id. Replace a placeholder by dropping a file with the **same id** into
`assets/sfx/` (or `assets/music/` for music), then run:

```text
python tools/add_sounds.py
```

and reload the project in the Defold editor. `add_sounds.py` prefers `.ogg` over `.wav` when both
exist, regenerates the matching `.sound` component and `main/sfx.go`.

Legend: **status** = `placeholder` (generated by `tools/make_sfx.py`) or `final` (human-supplied).
**bus** = `sfx` or `music`. **loop** = `yes` for looping clips.
